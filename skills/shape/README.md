# shape

The default planning door: the agent shapes the work (context, the right planning piece, the backbrief) before
anyone builds it, then delegates. A compound skill: its pieces stay separate skills, slash-only. Rules in
[SKILL.md](SKILL.md); history in [CHANGELOG.md](CHANGELOG.md).

| Pieces | When |
|---|---|
| `brainstorm` | the idea is still open |
| Pelo resultado (inside shape) | a thing named without a number |
| `interview` | many decisions, rich context |
| `domain-plan` | a screen, a flow, a service |
| `design-taste` | taste and quality |
| `backbrief` | always, before building |
